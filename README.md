> **拾光排版器** 是一款专为微信公众号创作者、技术写作者及自媒体达人打造的现代化全功能 Markdown 排版工具。不仅内置 **35 套精美主题与优雅卡片**，更完美支持 **Markdown 全量语法、KaTeX 数学公式、Prism.js 代码高亮、Mermaid 动态图表**，并支持一键复制微信草稿、导出 Markdown、HTML、PDF 及高清长图！

## 🌟 核心功能亮点

1. **🎨 35 套精美主题与卡片**：涵盖轻量基础、标题风格、优雅卡片三大系列，一键切换，文章质感秒提。
2. **📝 全功能 Markdown 语法**：
   - 标题、加粗、斜体、删除线、行内代码、超级链接。
   - 嵌套引用、有序/无序列表、**任务清单 (Task Lists)**、**高级表格 (GFM Tables)**。
3. **📐 KaTeX 数学公式支持**：支持行内公式（如 $E = mc^2$）与块级复杂数学公式（微积分、矩阵、概率分布等）。
4. **📊 Mermaid 动态图表引擎**：支持直接编写 Mermaid 代码，实时渲染为流程图、时序图与架构图。
5. **📤 多格式全能导出**：
   - **一键复制微信草稿**：完美保留富文本与样式，直接粘贴至微信公众号后台。
   - **📄 导出 Markdown 文件 (`.md`)**：方便本地归档与迁移。
   - **🌐 导出 HTML 文件**：带内联样式的独立网页文件。
   - **📑 导出 PDF 文件**：高质量分页打印文档。
   - **🖼️ 导出高清长截图 (`.png`)**：适合社群与朋友圈分享。

## 🚀 小白零基础上手与本地运行指南

即使您没有任何编程基础，也可以通过以下步骤在本地或云端运行本项目：

### 1. 环境准备
- 确保您的电脑上安装了 [Node.js](https://nodejs.org/) (建议版本 v18 或更高)。

### 2. 下载与安装依赖
打开终端（Terminal / 命令行窗口），进入项目根目录，运行以下命令安装所需依赖：
```bash
npm install
```

### 3. 启动本地开发服务
```bash
npm run dev
```
启动成功后，终端会显示访问地址（通常为 `http://localhost:3000`）。在浏览器中打开该网址即可开始体验拾光排版器！

## 📦 线上部署指南 (一键发布上手)

如果您遇到部署报错（如 Git 远程分支或权限问题），推荐使用以下最稳定、最简单的部署方式：

### 1. Vercel 部署 (推荐，免费且极速)
1. 将本项目代码下载并通过 ZIP 上传至 GitHub，或通过 GitHub 仓库导入。
2. 登录 [Vercel](https://vercel.com/)，点击 **Add New -> Project**，导入您的 GitHub 仓库。
3. 检查构建设置（通常自动识别）：
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. 点击 **Deploy**，几秒钟后即可获得一个专属的线上访问链接！

### 2. 生产环境打包与运行 (云服务器 / 容器)
如果您需要在自己的云服务器或容器中运行完整生产版本：
```bash
# 1. 执行生产打包
npm run build

# 2. 启动生产服务器
npm run start
```

## 💡 新手使用小贴士

1. **如何预览排版效果？** 
   - 可以在左侧编辑器中自由修改 Markdown 原文，中间的“414px 手机高保真预览框”会实时呈现最终排版效果。
2. **如何复制到微信公众号？**
   - 点击左下角的 **「复制微信草稿」** 按钮，然后在微信公众号后台文章编辑框中直接 `Ctrl + V` (或 `Cmd + V`) 粘贴即可，所有主题样式、表格与公式将完美保留！
3. **数学公式与图表怎么写？**
   - 数学公式使用 `$` 包裹（如 `$E=mc^2$`），块级公式使用 `$$`。
   - 流程图与图表使用 ` ```mermaid ` 代码块编写即可自动渲染。
